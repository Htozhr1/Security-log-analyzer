# Security Log Analyzer 🔐

## Overview
A Python-based cybersecurity project that analyzes simulated login logs and detects repeated failed authentication attempts.

## Features
- Analyzes sample login records
- Counts failed login attempts per IP address
- Generates alerts when an IP reaches 3 failed attempts

## Technologies
- Python 3
- GitHub Codespaces

## How to Run
Run python3 log_analyzer.py in the terminal.

## Disclaimer
This is an educational project using simulated data, not a production security monitoring system.
